# P01-Procedural-Tree-Generator-
ANGM 3311 - Project 01 Procedural Asset Generator 

"Tree Forge" is a procedural tree generator that creates a tree asset that is capable of altering tree height, crown spread, branching levels, branches, foliage density, branch direction, tree colors, and a seed randomizer. This can be used to create easy low-poly assets to design environments.
